# Rammo prototype

Navigation prototype of the Rammo tree of life: landmark trail, tree view ("Ver árvore") and
compare ("Comparar"). Static files only; sample of the real Rammo v8 tree (the lion's lineage
plus 16 reference organisms). Images: Wikimedia Commons, credits in each profile.

`app/` is the real Rammo app (rammo-life-tree frontend, current layout) built with
`npm run build:sample`: it answers its GraphQL queries in the browser from the same sample,
so it runs on GitHub Pages without a server. Open https://brunosantoss9719-ux.github.io/rammo-prototype/app/
