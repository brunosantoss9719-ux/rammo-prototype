# Rammo prototype

Two prototypes of the Rammo tree of life, served by GitHub Pages:

- **`/app/` (current):** the real Rammo app (rammo-life-tree frontend, `main`) running over an
  illustrative tree of about 1,000 animal groups (`app/sample/protoData.js`). It answers its
  GraphQL queries in the browser, so it needs no server. Where there is no photo it shows an
  illustration of the group. Texts and photos are prototype data, not published taxonomy.
  https://brunosantoss9719-ux.github.io/rammo-prototype/app/
- **`/` (earlier study):** static navigation prototype over a sample of the v8 tree (the lion's
  lineage plus 16 reference organisms). Images: Wikimedia Commons, credits in each profile.
